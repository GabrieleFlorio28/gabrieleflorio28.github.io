Vulnerable Lab

Laboratorio didattico containerizzato. Un ambiente multi-container controllato, progettato con Docker e Docker Compose, per lo studio pratico delle vulnerabilità web e applicative più comuni.

  • 4servizi Docker
  • 4reti dedicate, una per scenario
  • 4porte esposte, dalla 5000 alla 5003
  • 1script PowerShell di test automatico

Come è fatto

Ogni scenario gira in un servizio separato, collegato alla propria rete. Seleziona una rete per vedere di cosa si occupa.

Docker Compose Un host, quattro servizi, quattro reti dedicate

SQL Injection

Rete
sql_net
Porta
5000

Scenario dedicato a SQL Injection, isolato nella rete sql_net ed esposto sulla porta 5000.

In breve: input non filtrato che permette di alterare le query inviate al database.

I quattro scenari

Le vulnerabilità più comuni, spiegate con uno schema. I disegni mostrano il meccanismo in generale, non il codice del laboratorio.

SQL Injection

:5000
sql_net

L'input dell'utente finisce dentro una query senza controlli, e chi lo scrive può cambiarne il significato.

Broken Authentication

:5001
auth_net

Login e sessioni implementati in modo debole permettono di arrivare ai dati di un utente senza esserne il proprietario.

Privilege Escalation

:5002
priv_net

Un utente ottiene permessi superiori a quelli del proprio account, fino a quelli di un amministratore.

Security Misconfiguration

:5003
misconf_net

Impostazioni predefinite o sbagliate lasciano il servizio più esposto del necessario.
